PANDUAN FOLDER: images/mobil/
=============================
Folder ini untuk menyimpan foto utama tiap model mobil Toyota 2026.

Cara menambahkan foto mobil agar tampil:
1. Simpan file foto mobil (format .jpg / .jpeg / .png / .webp) ke dalam folder ini.
   Contoh: images/mobil/innova-zenix.jpeg atau images/mobil/innova-zenix.jpg
2. Buka file cars-2026.js lalu daftarkan path gambar di CAR_COLOR_OPTIONS pada urutan pertama:
   { key: "white", image: "images/mobil/innova-zenix.jpeg", studio: "dark" }
   (Gunakan studio: "dark" untuk latar foto hitam atau "light" untuk latar putih/transparan.
   Saat ini seluruh 27 dari 27 model sudah terhubung ke folder images/mobil/.)
